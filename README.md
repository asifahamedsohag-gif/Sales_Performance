# 📊 Sales Performance Dashboard

## 📈 Dashboard Overview

An interactive **Sales Performance Dashboard** designed to analyze sales performance across regions, products, and months.

The dashboard provides a clear overview of key sales KPIs and helps identify sales trends, regional performance, product performance, and monthly sales patterns.

---

## 🖼️ Dashboard Preview

![Sales Performance Dashboard](image/Sales%20Performance.jpg)

---

## 🎯 Project Objective

The main objective of this project is to transform sales data into an interactive and visually informative dashboard that supports sales performance analysis and data-driven decision-making.

The analysis focuses on:

- Total sales
- Total quantity sold
- Average sales per order
- Product category count
- Regional sales performance
- Product-wise sales performance
- Monthly sales trends

## 📊 Dashboard Features

### 1. Sales Performance by Region

The dashboard provides a regional analysis of total sales across:

- Central
- East
- North
- South
- West

The regional visualization makes it easier to compare sales contribution across different geographical areas.

---

### 2. Total Sales by Product

The product-level visualization analyzes sales performance across different products, including:

- Desk Chair
- External SSD
- Headset
- Keyboard
- Laptop
- Monitor
- Mouse
- Printer
- USB Hub
- Webcam

This helps identify products with higher and lower sales performance.

---

### 3. Total Sales by Month

The monthly sales trend provides an overview of how sales changed throughout the year.

It helps identify:

- Monthly sales fluctuations
- High-performing months
- Low-performing months
- Overall sales trends
- Seasonal sales patterns
